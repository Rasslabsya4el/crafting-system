# Crafting oracle (prototype)

Given a Path of Exile 1 item spec, find how to craft it from a white base, what it costs on average, and the best few ways.
A nested, independent git repository inside `poe-junkroan-v2`. Start with `AGENTS.md` (rules of work), then `docs/BRIEF.md`
(mission and phases), then `docs/STATE.md` (where things stand today).
