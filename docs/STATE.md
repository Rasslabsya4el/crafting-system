# Current state — readable route reports (2026-09-21)

## What works and how to see it

Ordinary PoE 3.29 prototype: sourced action distributions, exact/seeded policy costs,
parameter selection, terminal utility distributions and a finite ranked policy library.
Owner-facing Russian HTML is generated by the real planner, with dark theme and one
fractional digit. Each route has steps, stop/reset conditions, stage probabilities,
expected material counts/costs, mean/p90, risk and expandable raw data. Tiny nonzero
probabilities retain a less-than0.1% label plus approximate one-in-N odds.

```powershell
python -m tools.collect_evidence --output-dir out/evidence-final
python -m craftoracle report examples/helmet_life_chaos_res.yaml --loadout data/loadouts/endgame.json --output-dir out/reports/helmet --evidence-dir out/evidence-final
python -m craftoracle report examples/bow_value_table.yaml --loadout data/loadouts/endgame.json --compare-thresholds 60,100 --output-dir out/reports/bow --evidence-dir out/evidence-final
```

Open out/reports/helmet/index.html or out/reports/bow/index.html in a local browser.
Each folder also contains plan.json and copied proof/log/XML/CoE artifacts. The report
needs no server or network. Source-builder tests need the ignored local PoB/CoE snapshots.
All pytest temporary files remain in .pytest_tmp. No third-party raw files are committed.
