# New code from scratch; the old prototype is a read-only reference

The code is written from scratch on the new data model (ADR-0003, ADR-0009). The old prototype on branch `archive/prototype` (tip `da384a6`) is a read-only reference: it was built on a Path of Building extraction and on hand-written recipes, which ADR-0003 and ADR-0001 replace.

Carried over: the hand-checked cases H1–H3 and the 41 known answers, as test fixtures after a re-check against admitted sources; the mechanics fact sheets, each re-audited under ADR-0004 and ADR-0005, with unconfirmed claims becoming open questions; the source list; the Craft of Exile offline cross-check as an oracle; the old helmet and bow numbers as a cost bar (ADR-0013).

Not carried: the Path of Building extraction, the recipes and optimizer, the HTML report, the process docs.

Origin: [Design grill round 2: data, batches, repo](https://github.com/Rasslabsya4el/crafting-system/issues/3) Q16.
