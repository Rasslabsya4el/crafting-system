# R12 is the first slice, tested on the guide's weight-share formula

The first vertical slice is benchmark route R12, the +1 Lightning amulet: start from a bought amulet with fractured Lightning Resistance, then Harvest Reforge Lightning. It crosses the data fetch, the amulet pool, Chaos Orb, the Harvest reforge, the buy start, the compressed state, the kernel, the solver and the report. The rest of B1 widens from it.

Acceptance: the guide's numbers are single-draw weight shares, so the test reproduces the formula on 3.29.3.3 weights with the pool builder: 200/14,950 = 1.338% (Reforge Lightning), 200/6,950 = 2.88% (with fractured Lightning Resistance), and the Chaos share 200/214,650 = 0.0932% at item level 86, with the guide's 200/213,850 recorded as an 800-weight difference. (Since ticket #310 the 800 is gone: it was `IncreasedCastSpeed2Royale`, a Battle Royale copy that the game does not roll, and the pool now gives the guide's 200/213,850 = 0.0935%.) The solver's per-click chance that the finished item holds the mod is reported next to them and is not compared with the guide.

Origin: [Design grill round 3: modules, verification, process](https://github.com/Rasslabsya4el/crafting-system/issues/4) Q22, which already allowed checking "the same formula on 3.29 weights" if they differ; pinned after [Harvest reforges in 3.29](https://github.com/Rasslabsya4el/crafting-system/issues/10) showed the guide's percentages are weight shares, in [R12 end to end: CLI, JSON policy and text tree](https://github.com/Rasslabsya4el/crafting-system/issues/26).
