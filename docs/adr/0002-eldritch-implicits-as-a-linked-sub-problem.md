# Eldritch implicits are a separate sub-problem linked by one dominance flag

Eldritch implicits (Eater of Worlds and Searing Exarch) are planned as a separate sub-problem joined to the main explicit-mod model by a single dominance flag, while influence mods are ordinary explicits inside the main model. Implicits and explicits are rolled by different currencies and barely interact, so keeping them apart avoids multiplying the main state by the implicit state. How the link works is designed at the B2 grill ([Design grill round 3: modules, verification, process](https://github.com/Rasslabsya4el/crafting-system/issues/4) Q23).

Settled in the feasibility session before [Design grill round 1: foundations](https://github.com/Rasslabsya4el/crafting-system/issues/2) and recorded there under "Settled before the grill".
