# Eldritch implicits are a separate sub-problem linked by one dominance flag

Eldritch implicits (Eater of Worlds and Searing Exarch) are planned as a separate sub-problem joined to the main explicit-mod model by a single dominance flag, while influence mods are ordinary explicits inside the main model. How the link works is designed at the B2 grill ([Design grill round 3: modules, verification, process](https://github.com/Rasslabsya4el/crafting-system/issues/4) Q23).

**Amended by [ADR-0025](0025-eldritch-implicits-linked-by-dominance.md)** ([grill B2](https://github.com/Rasslabsya4el/crafting-system/issues/93)): the link is not a stored flag but a grade and a goal contribution kept per side, with dominance derived from the grades.

Settled in the feasibility session before [Design grill round 1: foundations](https://github.com/Rasslabsya4el/crafting-system/issues/2) and recorded there under "Settled before the grill".
