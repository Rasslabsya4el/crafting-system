## Requirements
1. Exact command from repo root must work with no install, no PYTHONPATH override and no
   writes outside crafting: `python -m craftoracle plan examples/helmet_life_chaos_res.yaml
   --loadout data/loadouts/endgame.json`. Add minimal root package bootstrap whose __path__
   points only to repository src/craftoracle (Path arithmetic), plus src module main delegating
   argparse CLI. No sys.path modifications to external dirs, no pip/environment setup.
2. `plan SPEC --loadout LOADOUT [--json]` loads existing ActionData and validated inputs, runs
   evaluate_policies, prints ranked table with id/name, exact success probability(ies), expected
   attempts perstage, expected totalcost,p90cost,method,withinbudget. Follow table with each
   policy's ordered steps/decisions, expected terminal utility, irreversible-risk/rareinputs,
   assumptions or explicit shared-assumption references. Display enough precision to distinguish
   helmet probabilities1e-5..1e-3. Never round tinypositivechance to zero, no fabricated prices.
3. JSON mode serializes all fields/distributions/source assumptions, includes schema_version1,
   input base/ilvl/quality, priceunit, ranked policies, unavailable candidates with reasons.
   Convert OutcomeClass dicts to list objects rather than stringifying tuple keys; no NaN/Infinity
   invalid JSON. Exit0 if reachable policies exist, exit2 with meaningful stderr for invalidinput,
   unreachable/allblocked, missingprice/permission. Do not swallow uncaught programming errors.
4. Optional `--threshold` override only utility specs; returns same distribution evaluated under
   different stopping rule, no silently changing itemrequiredtarget. No flags bypassing Q9.
   README documents command, JSON mode, input JSON-compatible YAML, example prices invented,
   exact-under-provisional assumptions and explicit blocked families. No full-project claim.
5. Console user-facing content focuses on crafting decisions/costs; implementation limitations
   belong in assumptions. Under a minute for helmet, no network, maxoneprocess beyond pytest.
