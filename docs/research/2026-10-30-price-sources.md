# Price sources: price history and the trade API

Ticket: [#13](https://github.com/Rasslabsya4el/crafting-system/issues/13) (map [#1](https://github.com/Rasslabsya4el/crafting-system/issues/1); decision served: Q5 and Q21 in [#4](https://github.com/Rasslabsya4el/crafting-system/issues/4)). Date: 2026-10-30. Claim ids `PRC-nn`. Everything below was checked on 2026-10-30 against primary sources (official docs, the services' own docs and responses, the repositories). Raw responses are in `.claude/scratch/research-price-sources/` (not committed).

## Answer

**poe.ninja's documented economy endpoints cover every category except "a rare base with a given mod"**: currency, lifeforce, fossils, chaotic resonators and Shrieking/Deafening essences from the exchange overview; beasts and bases (item level 82-86 and influence) from the stash overview. Other time ranges exist but are **not in poe.ninja's docs**: per-item daily history for the current and for previous leagues (Mirage, Ancestors), and CC-BY-SA dumps back to 2016. poe.watch (daily history, `exchange/ratios`) and GGG's own public Currency Exchange digests are the second and third source for currency. **A rare base with a fractured mod is priced by no aggregator; only the official trade API can do it**, and GGG's documentation does not cover that API: its developer docs call reverse-engineering endpoints outside the docs a Terms of Use breach, new OAuth applications are closed, and the trade API rate-limits the whole user (IP or account) across all tools. **No maintained Python wrapper exists.** Maintained code (Awakened PoE Trade, Path of Building, Sidekick, PoENavi) is all inside apps. Recommendation: fork the MIT `NickRyder/PoEQuery` query model and header-driven limiter (stale since 2021), refresh it against GGG's `data/filters` and `data/stats` lists, and write about 300 lines ourselves. Treat the trade fetcher as an opt-in, user-run, low-volume command: it is the only part of `prices` with a policy risk and an unverified Cloudflare risk.

## Recommendation for the `prices` module

**Source per category** (the solver reads only the dated local file; the fetcher is separate, as Q5 says):

| Category | Primary | Notes |
|---|---|---|
| Currency, lifeforce, catalysts, Fracturing Orb | poe.ninja `exchange/.../overview?type=Currency` | Chaos is `core.primary`; Divine equivalent from `core.rates` |
| Fossils, Chaotic resonators | poe.ninja `exchange/.../overview?type=Fossil` / `Resonator` | Alchemical resonators have no source anywhere: manual price or unavailable |
| Essences | poe.ninja `type=Essence` | Gaps in lower tiers: poe.watch `/exchange/ratios`, flagged low confidence, else manual |
| Beasts | poe.ninja stash `type=Beast` | Require a minimum `count` (poe.ninja's own charts use `count >= 5`) |
| Bases by item level and influence | poe.ninja stash `type=BaseType`, key `(name, levelRequired, variant)` | Minimum `count` as above; outside item level 82-86 no aggregator data |
| Base with a mod (fractured etc.) | official trade API | Opt-in; until it exists, price per query by hand (Q5) |

**Fallback order for a missing or thin price (Q21)**, stopping at the first that passes the sample test, each result stamped with source, league, date and a warning when it is not the current snapshot:
1. poe.ninja, current league, current overview.
2. poe.ninja, same league, earlier days (history endpoints, PRC-18): median of the last 7 days with `count >= 5` (items) or non-zero `volumePrimaryValue` (exchange).
3. poe.watch, current league (`/exchange/ratios`, then `/get`), then `/history`.
4. Previous league at the same league age (Mirage, Ancestors) or Standard, loudly flagged as a different economy (PRC-19); dumps (PRC-20) only if the owner approves the download.
5. Buy actions only: the official trade API, opt-in and user-run.
6. A hand override always wins. If nothing passes, the action is unavailable and the report lists it (Q21).
GGG's Currency Exchange digests (PRC-08) can replace steps 2-4 for currency only, after a mapping from item metadata ids to names; not needed for v1.

**What blocks or constrains:**
- **Trade API policy and Cloudflare** (PRC-01, 05, 07, 31): no permission exists for unattended use and a challenge may stop a script. This needs an owner decision (see Open), not a coding fix. R12 does not wait for it: the buy price is entered by hand (Q5).
- **No maintained Python wrapper** (PRC-33 to 41): a fork and about 300 lines.
- **History endpoints are undocumented** (PRC-18): the fetcher must treat a 404 or a changed shape as "source failed" and move down the order, never crash.
- **No per-line sample count on the exchange overview** (PRC-13): size test is `volumePrimaryValue`; the "snapshot older than 7 days" warning (Q21) uses our own fetch date because poe.ninja gives no timestamp there.
- **Coverage gaps**: lower-tier essences, Alchemical resonators, bases outside item level 82-86 (PRC-14, 15).
- **Terms**: poe.ninja states no licence for the API; send a descriptive User-Agent, honour caching, keep volume low (PRC-10). Public releases need GGG's non-affiliation line (PRC-06); poe.ninja dumps are CC-BY-SA (share-alike) if ever used (PRC-20).

## Open

1. **May we run the trade API unattended?** No GGG statement found either way (PRC-01, 05, 07). Settles by: the owner decides the risk, or asks GGG support (the ToU names `support@grindinggear.com`); safest default is a user-invoked command that only runs on the owner's request.
2. **Does a plain HTTP client with a proper User-Agent pass Cloudflare on `api/trade`, and what are today's search/fetch limits?** Not tested by design (PRC-29, 31). Settles by: one owner-approved manual smoke test in the build task, headers saved as a fixture.
3. **Mapping repoe-fork mod to trade stat id** (hash derivation or text match): not worked out. Settles by: diffing `data/stats` text against the stat translations for the R12 mod and 20 more.
4. **poe.ninja history endpoints** are used by the site but undocumented; stability unknown. Settles by: asking poe.ninja (their docs name Discord) or a periodic contract test in CI marked allowed-to-fail.
5. **Meaning of `count` (maximum 399 seen) and `volumePrimaryValue` units** in poe.ninja: not documented. Settles by: asking poe.ninja, or choosing thresholds empirically.
6. **Why exchange `Currency` has exactly 100 lines and Essence 64 of 106**: other crafting orbs look complete (PRC-14), but a cap is not excluded. Settles by: comparing with poe.watch `/exchange/ratios` names when the fetcher is built (124 of its currency names are absent from poe.ninja `Currency`, mostly other poe.ninja categories: tattoos, astrolabes, omens).
7. **Dump contents and the GGG digest after hour one** were not sampled beyond the listing (no downloads without the owner's yes; one digest hour read).
8. **League rollover**: at league end `Allflame` moves to `oldEconomyLeagues`; the fetcher must read `economy/leagues` each run instead of hard-coding the name.
9. The Python-wrapper search is broad but not exhaustive (GitHub topic and code search, 17 PyPI names). A wrapper under an unusual name could exist.
